These are copies of public page responses, not the sites' project files or the mobile apps' code. Styles, scripts, fonts, and images still load from the original sites. Opening an HTML file directly from disk may not reproduce the page because root-relative URLs and site scripts expect the original domain. Use the screenshots for layout and visual reference. Superpower reveals sections while scrolling, so separate views preserve those sections more reliably than one full-page image.

For the redesign, the Superpower captures show its full-width hero, floating navigation, step cards, product display, and searchable test catalog. The Cal AI captures show its phone mockups, feature display, benefit cards, and FAQ layout.
